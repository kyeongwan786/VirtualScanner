NEW_WORK V3 중앙 송신기 빌드 안내
================================

V3는 중앙 PC에서 쓰는 HTML/CSS 기반 송신기입니다. 신분증 이미지와 PDF를 각각
단독으로 또는 함께 추가할 수 있습니다. 이미지를 추가하면 OCR이 실행되고, PDF를
추가하면 페이지 JPG로 변환됩니다. OCR 결과와 종류별 idCrop 영역을 확인한 뒤
선택한 접수 자리의 Receiver로 보냅니다.

신분증 JPG/PNG를 2~50장 한 번에 선택하거나 신분증 패널에 함께 끌어 놓으면 묶음
검토 창이 바로 열립니다. 이미지는 최대 4개씩 올리고 별도 OCR 엔진 2개에서 병렬
인식합니다. 신분증 이미지는 업로드되는 즉시 미리보기에 표시하고, OCR 결과는 인식이
끝나는 즉시 채웁니다. 첫 이미지부터 확인할 수 있으며 각 신분증의 종류와 idCrop
영역을 조정한 뒤, 마지막
항목에서 **모두 저장하고 전송**을 누르면 각 신분증이 별도 접수
건으로 선택한 Receiver의 Relay 대기열에 순서대로 등록됩니다. 특정 신분증에 PDF를
붙이고 **PDF와 함께 뒤에 전송**을 선택하면 일반 신분증 작업을 먼저 등록한 뒤, 해당
신분증과 변환 PDF를 한 접수 건으로 등록합니다. 메인 화면의 PDF 변환 목록은 신분증과
자동 연결하지 않으며 별도 전송용으로 남습니다. 한 장씩 올리는 기존 흐름도 유지됩니다.

신분증 OCR 및 idCrop 검토 기능은 기존 처리 흐름을 사용합니다. idCrop 박스의
규격은 신분증 종류와 SK/KT 처리에 따른 기존 코드 규격을 따르며, 박스 크기는
고정이고 위치를 조정할 수 있습니다. PDF는 페이지별 JPG로 전송됩니다.

송신기 상단의 **긴급 중단**은 `전체 폐기` 입력을 확인한 뒤 Relay를 잠그고
대기 작업을 지웁니다. 온라인 Receiver는 최대 2초 내 명령을 확인해 NEW_WORK로 받은
작업자료와 이 Receiver가 `ready`에 올린 파일을 지우고 자기 Windows 설치 폴더를
제거합니다. 기존 SK/KT 결과, 데이터베이스, 백업, 설정은 보존합니다. 다른 최신 V3
송신기도 Relay 잠금을 확인하면 송신 대기 자료와 설치 폴더를 제거합니다.
꺼져 있거나 네트워크가 끊긴 PC는 명령을 즉시 받지 못하며, 다시 Relay에 연결하거나
프로그램을 실행할 때 처리됩니다. 이미 실행 중인 업무페이지나 별도 스캐너는 종료하지
않습니다. 구버전 앱은 Relay 연결이 차단되지만 자체 종료·제거는 하지 못합니다. Render
서비스와 Render 로그, 저장소의 소스 코드는 삭제하지 않습니다.
Relay 잠금은 Relay 데이터 폴더에 기록되므로, 임시 저장소를 쓰는 Render 배포가
재시작되면 잠금 상태가 사라질 수 있습니다. Windows 설치본에서 프로그램 폴더 자동
삭제가 지원됩니다. 이 기능을 사용하기 전 Relay와 Sender/Receiver를 모두 갱신하세요.

Windows 빌드
------------

Windows x64에서 Python 3.12 x64를 설치한 뒤 이 ZIP을 풀고
`build_windows_v3.bat`을 실행하세요. 성공하면 다음 실행 파일이 생성됩니다.

    dist\new_work_v3\new_work_v3.exe

이 ZIP은 OCR 모델 파일을 포함한 Windows 빌드 소스입니다. 완성된 Windows EXE는
포함하지 않습니다. Windows에서 직접 빌드해야 하며, 이 저장소 갱신 과정에서는
macOS에서 Windows EXE를 만들거나 검증하지 않았습니다.

송신기의 **Relay 설정** 버튼은 빌드에 포함된 `relay-provisioning.json`에서 Relay 주소와
중앙 토큰을 자동 저장합니다. 접점 관리의 Relay 자리 ID도 파일에 등록된 자리 목록에서
선택할 수 있습니다. 자동 설정을 포함해 빌드하려면 비밀 설정 파일을 이 폴더의
`relay-provisioning.json`으로 복사한 뒤 빌드하세요. 비밀 파일은 소스 ZIP이나 저장소에
포함하지 않습니다.

수신 PC에는 별도 `NEW_WORK-Receiver-V3-Windows-Build.zip`의 Receiver를 설치합니다.
`Receiver 설정`에서 자리만 선택하고 **자리 설정 적용**을 누르면 해당 Relay 주소와
자리 토큰이 저장됩니다. Receiver EXE에는 모든 자리 토큰이 들어가므로 EXE를 가진 사람은
다른 자리의 토큰도 추출할 수 있습니다. 중앙 Sender EXE에는 중앙 토큰만 넣습니다.
Render 주소와 작업 흐름은 `RECEIVER_README.md`를 참고하세요.

V1은 별도 OCR 전용 프로그램이며 `NEW_WORK-V1-Windows-Build.zip`에서 빌드합니다.
