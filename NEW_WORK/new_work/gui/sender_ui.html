접점 설정

현풍부터 헬리오스까지 17개 자리가 자동 등록됩니다. 각 Receiver에서는 설치 후 자기 자리를 선택하고 설정을 저장하면 됩니다.

Relay 설정

Render Relay 주소와 중앙 송신 토큰을 설정합니다.

토큰은 보안상 다시 표시하지 않습니다. 새 토큰을 입력하면 교체되고, 비워 두면 현재 저장된 토큰을 유지합니다.

긴급 중단 · 전체 폐기

이 명령은 취소할 수 없습니다. 아래 작업 자료와 Relay가 잠깁니다.

  • Relay에 대기 중인 전송 작업과 자료를 삭제합니다.
  • 연결된 최신 Receiver의 NEW_WORK 수신 자료와 이 앱이 스캐너 ready에 등록한 파일을 삭제하고 프로그램을 종료합니다. Windows 설치본은 자동 제거 대상이며, 오프라인 PC는 다시 연결될 때 명령을 받습니다.
  • 송신기 작업 자료를 지우고 송신기를 종료합니다. Windows 설치본은 자동 제거 대상입니다. macOS에서 소스로 실행한 폴더는 자동 삭제되지 않습니다.

기존 SK/KT 결과, 데이터베이스, 백업과 설정은 보존됩니다. 긴급 잠금은 Relay의 Neon DB 연결을 확인한 뒤 기록됩니다.
