NEW_WORK Windows 빌드 안내
=========================

중앙 OCR 앱과 Receiver는 V1/V2별 ZIP으로 나뉩니다.

- V1 중앙 앱: 접수 PC에서 실행하고 현재 PC의 SK/KT 결과에 직접 저장
- V2 중앙 앱: 중앙 PC에서 실행하고 선택한 PC의 V2 Receiver로 전송
- V2 Receiver: V2 Relay OCR 수신과 PDF 서류 스캔 대기열 관리

V1은 OCR 전용으로 별도 Receiver가 필요 없습니다. 중앙 OCR V1/V2와 V2 Receiver는
각각 별도 ZIP으로 제공합니다. ZIP에는 Windows EXE가 아닌 Windows에서 빌드할
소스가 들어 있습니다. 실제 Windows 빌드 및 실행 검증은 아직 수행되지 않았습니다.
