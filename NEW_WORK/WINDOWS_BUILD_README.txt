NEW_WORK Windows 빌드 안내
=========================

중앙 OCR 앱과 Receiver는 V1/V3별 ZIP으로 나뉩니다.

- V1 중앙 앱: 접수 PC에서 실행하고 현재 PC의 SK/KT 결과에 직접 저장
- V3 중앙 앱: HTML/CSS 화면에서 OCR·PDF를 준비해 선택한 PC의 V3 Receiver로 전송
- V3 Receiver: Relay 자료함, 신분증 확인·저장, JPG 미리보기, 서류 스캔 대기열 관리

V1은 OCR 전용으로 별도 Receiver가 필요 없습니다. 중앙 OCR V1/V3와 V3 Receiver는
각각 별도 ZIP으로 제공합니다. ZIP에는 Windows EXE가 아닌 Windows에서 빌드할
소스가 들어 있습니다. 실제 Windows 빌드 및 실행 검증은 아직 수행되지 않았습니다.
